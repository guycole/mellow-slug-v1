# mellow-slug
This is the no-op mellow collector, it can be assigned to collectors as a task but does not perform any collection. Mellow Slug also serves as an example of a [Mellow Wombat](https://github.com/guycole/mellow-wombat) managed application.

In this example application, the observations list is intentionally empty. A production collector should implement domain-specific logic to gather and process observations before writing payload files.
